# JL-Agent 设计规范（Design System）

> 依据《05_UI-UX设计师.md》§七交付标准编制。实现基准：`frontend/css/app.css`。变更需同步本文件 + `docs/CHANGELOG.md`。

## 1. 设计 Tokens（色板）

## 2. 组件规范

| 组件 | 关键规则 |
|---|---|
| 按钮 `.btn` | 默认白底描边；`.primary` 主色实底白字；`.danger` 红字红边；hover 亮度微升；disabled 半透明 |
| 卡片 `.card` | 白底 + 1px 描边 + 圆角 12 + 阴影；头部 `h2` 15px/700 |
| 输入 `.grid input/select/textarea` | 灰底 #fafbfc；focus 蓝色 3px ring + 白底；宽度 100%（checkbox 例外） |
| 标签 `.tag` | 胶囊圆角 16；required=危险浅底 / optional=灰浅底 / ok=成功浅底 / on=主色实底 |
| 横幅 `.banner` | 警告语义（浅黄底/描边/深黄字）；错误用 `showBanner(msg, true)` 加红字 |
| 进度 `.progress-*` | 8px 圆角条 + accent→accent-2 渐变填充 |
| 折叠分组 `details.fs-fold` | 1px 描边 + summary 600 字重 + ▸ 箭头（open 旋转 90°） |
| 辅助栏 `.rail` | 左 224px/右 272px（sticky）；1240/1024/820 响应式收起 |
| 提醒栏 `.help-*` | 三段式：标题 13.5px/700 + 正文 12px + 脚注虚线分隔 |
| 弹窗 `.modal` | 遮罩 rgba(15,23,42,.45)；内容 560px/92vw + 大阴影 |

## 3. 排版层级

| 级别 | 字号/字重 | 用途 |
|---|---|---|
| h1（页面外） | — | 顶栏品牌 16px/700 |
| 卡片标题 h2 | 15px/700 | 分区标题 |
| 分组 summary | 13px/600 | 折叠分组 |
| 正文 | 14px/400 | 默认 |
| 次要 | 12.5px/600 | label 文字 |
| 弱化 | 11~12px | 说明/时间戳（≥AA 色） |

## 4. 响应式断点

| 断点 | 行为 |
|---|---|
| ≤1280 | 布局 max-width 1280 居中 |
| ≤1240 | 左 190px / 右 244px |
| ≤1024 | 隐藏右提醒栏 |
| ≤820 | 隐藏左流程栏 |
| ≤720 | grid 单列 |

## 5. 可访问性基线（WCAG AA）

- 正文对比度 ≥4.5:1；弱化文字最低 `--ink-mute`（禁止 `--muted` 用于正文）
- 所有可交互元素：`focus-visible` 2px 主色 outline（输入框用 3px box-shadow ring）
- Esc 关闭抽屉/弹窗；抽屉打开焦点落首个控件
- 状态不得仅靠颜色传达（配文字/图标）

## 6. 使用红线

1. 新增颜色必须进 `:root` tokens，禁止散落硬编码；
2. 组件样式优先复用（btn/tag/banner/progress），不复制变体；
3. 文案保持「真实优先」口径（降级标注【待联网核实】【待补充】）。
